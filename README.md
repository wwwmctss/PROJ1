Результаты разведочного анализа данных
1. Знакомство с данными и очистка:
- Размер исходного набора: 2000 строк и 21 столбец. Все признаки числовые, пропуски (NaN) и полные дубликаты отсутствуют.
- Были обнаружены физически некорректные нулевые значения в столбцах ширины экрана (sc_w) и вертикального разрешения матрицы (px_height). Нули заменены на медианные значения соответствующих колонок без искажения распределения.
2. Создание новых признаков (Feature Engineering):
- screen_area: физическая площадь дисплея в см² (sc_h * sc_w).
- total_camera: суммарное разрешение камер телефона в Мп (fc + pc).
3. Ключевые закономерности и выводы:
- Сбалансированность классов: Выборка идеально сбалансирована — на каждый из 4 ценовых классов приходится ровно по 500 записей (25%). Применение специализированных техник ресемплинга не требуется.
- Доминирующий признак: Объем оперативной памяти (ram) является главным разделяющим фактором для классификации. Между классами практически нет пересечений по квартилям: бюджетные модели сконцентрированы до 1500 Мб, флагманы — свыше 3000 Мб.
- Вторичные признаки: Емкость аккумулятора (battery_power) и площадь экрана (screen_area) показывают умеренную положительную связь с целевым классом — в старших ценовых категориях медианные значения параметров выше.
- Интерактивный анализ: График graph5.html подтверждает независимость распределения RAM от батареи: даже при слабом аккумуляторе телефоны с большим объемом оперативной памяти уверенно относятся к старшей ценовой категории.
